# Espaço Maker – UENP Campus Cornélio Procópio

Site estático do Espaço Maker da UENP – Campus Cornélio Procópio, publicado no GitHub Pages em
<https://espacomakerccp.github.io/>.

## Estrutura

```
.
├── index.html                  # Home
├── equipamentos.html           # Equipamentos
├── colaboradores.html          # Equipe (hub dos perfis)
├── labtecog.html               # LabTeCog
├── agendamento.html            # Agendamento
├── 404.html                    # Página de erro
├── colaboradores/              # Um perfil por colaborador
├── postagens/                  # Listagem e postagens
├── assets/
│   ├── img/                    # Imagens do site
│   │   ├── colaboradores/      # Fotos otimizadas dos perfis (320×320)
│   │   └── postagens/          # Cartazes das postagens
│   ├── style.css
│   └── site.js
├── design/                     # Arquivos-fonte (não usados diretamente nas páginas)
│   └── colaboradores/          # Fotos originais enviadas pelos colaboradores
├── robots.txt
└── sitemap.xml
```
